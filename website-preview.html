👥 Calendar Functionality by User Role

👨‍🎓 Student Features

When a student clicks on a calendar date:

  • 📋 View available time slots for tutors
  • ⏰ Select preferred time slot
  • 📝 Add reason for appointment
  • 📅 Book appointment with selected tutor

👩‍🏫 Tutor Features

When a tutor clicks on a calendar date:

  • 📊 Set day status (Available/Busy/Unavailable)
  • ⏰ Manage individual time slot availability
  • ✅ Check/uncheck specific time slots
  • 💾 Save availability settings

⚙️ Admin/Super Admin Features

When an admin clicks on a calendar date:

  • 📅 View current date status (Holiday/Regular)
  • 🎄 Mark date as holiday
  • ❌ Remove holiday status
  • 🔄 Update system-wide calendar settings
